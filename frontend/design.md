# UI Design System - TraceSwap

## Theme: Obsidian & Neon
- **Background:** Deep Black / Obsidian (`#0a0a0a` to `#1a1a1a`)
- **Accents:** Neon Green (`#00ff9d`), Cyan (`#00f3ff`), Purple (`#bd00ff`)
- **Typography:** Inter (Thin/Light weights)
- **Effects:** Glassmorphism (Blur 10px, White opacity 0.05), Gradient Borders

## Components

### 1. Layout
- **Sidebar/Navbar:** Glassmorphic, sticky.
- **Container:** Centered, max-width 1200px.

### 2. Cards (Tenders)
- **Bg:** `bg-white/5`
- **Border:** `border-white/10`
- **Hover:** Glow effect (box-shadow with accent color).

### 3. Forms
- **Inputs:** Transparent bg, bottom border or outline `white/20`.
- **Buttons:**
    - Primary: Gradient bg, text black/white.
    - Secondary: Outline, text white.

### 4. Visualizations
- **Charts:** Recharts with custom neon colors.
- **Status Indicators:** Glowing dots (Green = Open, Red = Closed).
